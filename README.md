# Seminario de Agentes

Itinerario de 6 sesiones para introducir el uso de agentes de IA en terminal a profesorado sin formación informática, anclado en tareas administrativas y docentes reales (no ejercicios de programación).

## Contenido

1. Instalación y primer contacto
2. Contexto persistente
3. Permisos y confianza gradual
4. Tareas multiarchivo
5. Control de versiones como red de seguridad
6. Cierre con proyecto propio

## Estado

En diseño. El itinerario detallado sesión por sesión está en discusión; el contenido de cada sesión se desarrollará a continuación.
