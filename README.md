# Seminario de Agentes

Itinerario de 6 sesiones para introducir el uso de agentes de IA en terminal a profesorado sin formación informática, anclado en tareas administrativas y docentes reales (no ejercicios de programación).

## Contenido

Cadencia semanal, 6 semanas. Instalación resuelta antes de la sesión 1 mediante guía enviada previamente, para dedicar el tiempo de contacto al primer uso, no al soporte técnico.

1. Instalación y primer contacto (120 min)
2. Contexto persistente (90 min)
3. Permisos y confianza gradual (90 min)
4. Tareas multiarchivo (90 min)
5. Control de versiones como red de seguridad (90 min)
6. Cierre con proyecto propio (90 min)
