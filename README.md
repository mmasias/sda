# Seminario de Agentes

Itinerario de 6 sesiones para introducir el uso de agentes de IA en terminal a profesorado sin formacion informatica, anclado en tareas administrativas y docentes reales (no ejercicios de programacion).

## Contenido

1. Instalacion y primer contacto
2. Contexto persistente
3. Permisos y confianza gradual
4. Tareas multiarchivo
5. Control de versiones como red de seguridad
6. Cierre con proyecto propio

## Estado

En diseño. El itinerario detallado sesion por sesion esta en discusion; el contenido de cada sesion se desarrollara a continuacion.
